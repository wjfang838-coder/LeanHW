Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- clk: input 1 bit.
- rst_n: input 1 bit.
- a: input 1 bit.
- match: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

Module and ports



Reset

rst_n is an asynchronous, active-low reset. Whenever rst_n is 0, match is immediately 0, the complete eight-sample history is cleared to 8'b00000000, and rising clock edges neither capture a nor assert match. Reset has priority if its assertion coincides with a rising edge. Releasing rst_n to 1 has no immediate effect: match remains 0 and the cleared history remains in place until subsequent rising edges update them. On the first rising edge after release, a is captured into the least significant position of the cleared history, while match is set from comparison of the preceding cleared history and is therefore 0.

At power-up before reset has ever been asserted and before any rising edge has assigned match, match is unknown. The implementation must leave it uninitialised, with no initial block or declaration initialiser establishing a value. The eight-bit sample history is likewise uninitialised before reset.

Timing

The circuit is rising-edge triggered. While rst_n is 1, each rising edge captures the current a value and updates match from the eight samples that preceded that edge. Thus match has one clock cycle of latency from completion of an eight-sample sequence: a sequence captured over eight post-reset rising edges is first observable after the ninth post-reset rising edge. match is registered and holds its value between rising edges, except that assertion of rst_n immediately forces it low. Any asserted match indication lasts one full clock cycle unless the next overlapping eight-sample window also matches, in which case it remains high across that edge.

Trace rows use the interface full-cycle observation convention: row k is sampled before active edge k, after inputs have settled, and the transition following that row performs active edge k. Row indices denote k times the interface step_ns after settling, with the interface sample_offset_ns applied; they do not imply a 10 ns clock. These observation coordinates do not impose any additional physical clock period or propagation delay on the circuit.

Behaviour

While rst_n is 1, every rising edge captures a into a continuously overlapping eight-sample history. The new a value enters as the least significant bit, every older value moves one position toward the most significant bit, and the oldest value is discarded. Both possible one-bit values of a are data. Changes to a between rising edges have no effect. Low and falling clk levels have no effect, and every rising edge repeats the operation without any busy or disabled mode.

On every rising edge with rst_n high, match becomes 1 exactly when the eight a samples captured before that edge, ordered from oldest to newest, equal 8'b01110001; otherwise match becomes 0. The a value captured on the current edge is not part of that comparison and can affect match only at the following rising edge. Each edge reevaluates the next overlapping eight-sample window. A pre-edge row k therefore shows the decision made at edge k-1 from samples through edge k-2. In particular, a sequence completed at cycle 8 is not reported at cycle 9 and is reported at cycle 10 under that row numbering.

Asserting rst_n low at any time immediately forces match to 0 and discards every previously captured sample, including when reset assertion coincides with a rising edge. While reset remains low, rising edges cannot capture a or assert match. Releasing reset does not restore discarded history; detection resumes using only fresh samples taken on later rising edges.
