Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. 1. Module and ports



3. Reset

The module has no reset input and no reset behavior. It contains no state. From power-up onward, including before any edge has occurred, every output is a definite combinational function of the current Opcode. No first reset edge or first step is required before any output becomes valid.

4. Timing

ALUSrc, MemtoReg, RegWrite, MemRead, MemWrite, ALUOp, Branch, JalrSel, and RWSel are all continuously evaluated combinational outputs of Opcode. Each has zero-cycle latency: a pre-edge observation already reports the value selected by the current Opcode. Changes, including repeated values and changes between any encodings, take effect without an edge. There are no pulses, periodic outputs, holds, completion states, interruption states, or restart states.

The circuit itself has no clock, cycle period, or propagation-delay law in this specification. Separately, for the evaluated trace, row k denotes the settled observation at k * step_ns using the interface's timing convention and sample offset; it must not be interpreted as an implicit 10 ns circuit clock.

5. Behaviour

Opcode is interpreted as its complete 7-bit encoding. All membership tests below are false for encodings not explicitly named.

ALUSrc is 1 exactly for Opcode 0000011, 0100011, 0010011, or 1100111; otherwise it is 0. A value of 0 selects the second register-file value as the second ALU operand, and a value of 1 selects the sign-extended lower 16 instruction bits.

MemtoReg is 1 exactly for Opcode 0000011; otherwise it is 0. A value of 0 selects the ALU value for register write-back, and a value of 1 selects the data-memory value.

RegWrite is 1 exactly for Opcode 0110011, 0000011, 0010011, 1101111, 1100111, 0110111, or 0010111; otherwise it is 0.

MemRead is 1 exactly for Opcode 0000011; otherwise it is 0.

MemWrite is 1 exactly for Opcode 0100011; otherwise it is 0.

ALUOp is 00 for Opcode 0000011, 0100011, 0010111, and 1100111; 01 for Opcode 1100011; 10 for Opcode 0110011 and 0010011; and 11 for Opcode 1101111 and 0110111. It is 00 for every other Opcode.

Branch is 1 exactly for Opcode 1100011 or 1101111; otherwise it is 0. It therefore indicates either a conditional branch encoding or JAL.

JalrSel is 1 exactly for Opcode 1100111; otherwise it is 0.

RWSel is 01 for Opcode 1101111 and 1100111, 10 for Opcode 0110111, 11 for Opcode 0010111, and 00 for every other Opcode. The encodings select, respectively, register write-back for 00, PC+4 for 01, immediate-generation write-back for 10, and PC plus immediate-generation write-back for 11.

Opcode continuously and combinationally selects all outputs with no inactive mode, priority, interruption, reset, or transaction state; changed or repeated input values take effect immediately and independently of prior inputs.
