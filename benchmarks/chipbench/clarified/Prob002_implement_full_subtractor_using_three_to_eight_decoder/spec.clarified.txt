Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- A: input 1 bit.
- B: input 1 bit.
- Ci: input 1 bit.
- D: output 1 bit.
- Co: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

3. Reset

There is no reset input and no reset behavior. The design has no state elements. From power-up onward, including before any edge has occurred, D and Co are determined immediately by the current A, B, and Ci values according to the laws below; neither output has an unknown or uninitialised interval.

4. Timing

D and Co are combinational outputs with zero-cycle latency from A, B, and Ci. There are no pulses, periodic signals, capture edges, holds, clears, completion events, or restart behavior. Simultaneous, repeated, or interrupted input patterns have no special timing effect: each output continuously reflects the inputs currently present.

The evaluated trace uses a full-cycle observation convention: row k samples the settled combinational outputs for that row's inputs before the model's transition. The model transition does not represent a circuit clock edge and does not change state. Thus trace rows are observation points only; the circuit itself has no period or cycle-based delay law.

5. Behaviour

A is the minuend, B is the subtrahend, and Ci is the incoming borrow. All three are one-bit values.

For every input combination, D = A ^ B ^ Ci.

For every input combination, Co = (!A && (B || Ci)) || (B && Ci). Equivalently, when A is 0, Co = B || Ci; when A is 1, Co = B && Ci. When B is 0, Co = !A && Ci; when B is 1, Co = !A || Ci. When Ci is 0, Co = !A && B; when Ci is 1, Co = !A || B.

These laws apply continuously, including simultaneous input changes and repeated or interrupted input patterns. There is no disabled encoding or transaction state, and every one of the eight possible combinations of A, B, and Ci is covered.

At all times, including simultaneous input changes and repeated or interrupted input patterns, A participates combinationally with D = A ^ B ^ Ci and selects Co = B || Ci when A is 0 or Co = B && Ci when A is 1, with no inactive mode or transaction state.

At all times, including simultaneous input changes and repeated or interrupted input patterns, B participates combinationally with D = A ^ B ^ Ci and selects Co = (!A && Ci) when B is 0 or Co = !A || Ci when B is 1, with no inactive mode or transaction state.

At all times, including simultaneous input changes and repeated or interrupted input patterns, Ci participates combinationally with D = A ^ B ^ Ci and selects Co = !A && B when Ci is 0 or Co = !A || B when Ci is 1, with no inactive mode or transaction state.

D continuously equals A ^ B ^ Ci with no reset, capture edge, latency, hold, clear, completion, or restart behavior, so a pre-edge row observes the value for the inputs present before that edge and input changes produce the corresponding first result combinationally.

Co continuously equals (!A && (B || Ci)) || (B && Ci) with no reset, capture edge, latency, hold, clear, completion, or restart behavior, so a pre-edge row observes the value for the inputs present before that edge and input changes produce the corresponding first result combinationally.
