1. Module and ports.



3. Reset.

Reset is active low and asynchronous. Whenever rst_n is low, match is 0 and all sequence progress is discarded, including when reset is asserted between rising clock edges or coincides with a rising edge. Deasserting rst_n alone does not change the reset state. On the first rising edge after release, data participates only when data_valid is 1; otherwise the reset state is retained. Before reset has ever been asserted, match is 0, the same value as during reset, and recognition begins with no established prefix.

4. Timing.

Recognition advances only on rising edges of clk. A steady clk level and falling edges have no effect. The match output is a Moore output derived from the current recognition state: the rising edge that samples the fourth valid bit of 0110 completes recognition, and match becomes 1 after that edge. It remains high for exactly one clock interval unless asynchronous reset forces it low sooner, and returns low at the next rising edge. Each repeated detection produces one such one-clock-interval pulse.

The evaluated trace uses full-cycle pre-edge rows. Row k denotes the settled sample at k times the interface step duration, at the interface sample offset; it shows outputs before that row's rising-edge transition. This observation convention is separate from the circuit law above and does not impose an additional clock period or propagation delay.

5. Behaviour.

With rst_n high, only each rising edge of clk advances or restarts recognition of 0110 from the then-current data and data_valid values, and match reflects the resulting recognition after that edge; a steady clk level and falling edges have no effect, while rst_n low dominates a simultaneous rising edge, repeated rising edges repeatedly apply the same sampling rule, and asynchronous reset can interrupt at any time.

Whenever rst_n is low, match is asynchronously forced to 1'b0 and all prior sequence progress is discarded; assertion interrupts recognition or an asserted match without waiting for clk, deassertion alone changes nothing, a rising clk while rst_n is low remains reset-dominated, and every repeated reset begins subsequent recognition afresh from the first rising-edge sample taken with rst_n high.

Data affects match only when sampled on a rising clk edge with rst_n and data_valid high: valid samples are compared in order against 0110, a mismatching 0 can immediately serve as the first bit of a new attempt where it is a valid prefix, a mismatching 1 restarts with no retained prefix, and on the edge after a completed match a valid 0 begins the overlapping next attempt while a valid 1 restarts; changes to data with data_valid low, between rising edges, or during reset have no effect.

On rising clk edges with rst_n high, data_valid=1 makes data the next sample for recognizing 0110, whereas data_valid=0 preserves an incomplete one-, two-, or three-bit prefix and has no effect before any prefix; exceptionally, data_valid=0 on the first edge after a completed match clears match and discards completed-sequence overlap, while reset dominates either value and repeated asserted cycles consume one data sample per rising edge.

Match is asynchronously 1'b0 while rst_n is low and stays low on release; using the frozen pre-edge row convention, the fourth valid sample completing 0110 is captured at the edge ending a low row and match is first observed as 1'b1 in the following row, remains high only until the next rising edge unless reset is asserted sooner, then returns low while that next edge either starts a new attempt from a valid 0 or otherwise restarts, so repeated detections each produce a one-clock-interval pulse and incomplete sequences produce none.

Before any sequence progress has been established, including at power-up as exercised by the frozen representatives and after reset, match is 1'b0. After reset, match remains 1'b0 until four rising-edge samples with data_valid asserted have formed 0110, so it is still low immediately before the edge that captures the final 0.
