Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- clk: input 1 bit.
- rst_n: input 1 bit.
- wave_choice: input [1:0].
- wave: output [4:0].

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

Module and ports



Reset

rst_n is an active-low asynchronous reset. Whenever rst_n is low, wave is 5'b00000 immediately, regardless of clk and wave_choice; reset assertion has priority over a simultaneous rising clk edge. Reset also places the square-wave cadence at the beginning of its 20-edge cycle and establishes downward travel for triangle mode. Keeping rst_n low keeps all of this reset state unchanged. A rising transition of rst_n alone causes no update. On the first rising clk edge after release, the selected mode applies its recurrence from the reset state: choice 00 retains wave at 0 and advances its cadence by one edge, choice 01 changes wave from 0 to 1, choice 10 changes wave from 0 to 31, and choice 11 retains wave at 0.

Before rst_n has ever been asserted low, wave is unknown. The implementation must leave its stored value uninitialised, with no initial block and no declaration initialiser. It remains unknown under choices 00, 01, and 10 until reset is asserted; a rising clk edge with choice 11 makes it 0.

Timing

wave is a registered 5-bit output, except that assertion of rst_n forces it asynchronously to 0. With rst_n high, wave changes only on a rising edge of clk and retains its value on falling edges and while clk is steady. Changes to wave_choice have no effect between rising edges. An update selected at a rising edge is observable immediately after that edge and in the following pre-edge sampled row. Reset release alone retains the current reset value until the next rising edge.

The square waveform has a period of 20 consecutive rising clk edges in choice 00: 10 edges in its low phase and 10 edges in its high phase. A reset or any edge in another choice restarts this cadence. Its first nine choice-00 rising edges retain the existing wave value, its tenth edge sets wave to 20, its next nine edges retain 20, and its twentieth edge sets wave to 0.

In a SpecIR worked trace, row k is the settled observation before that row's active edge, and successive rows are separated by timing.step_ns when that interface timing quantity is supplied. This observation convention is distinct from the circuit laws above: the circuit responds to rising clk edges and has no implicit 10 ns period or delay.

Behaviour

All wave_choice encodings are defined. With rst_n high, every rising clk edge applies exactly one of these laws:

For wave_choice 2'b00, the 20-edge square cadence advances. Changing into this choice starts a new cadence without independently reinitialising wave: the first nine consecutive edges retain the existing value, the tenth sets wave to 20, edges eleven through nineteen retain 20, and the twentieth sets wave to 0, after which the same cadence repeats.

For wave_choice 2'b01, wave becomes 0 if its prior value is 20; otherwise wave becomes its prior value plus one modulo 32. Thus a reset value of 0 becomes 1 on the first such edge. This rule applies on every repeated edge and on the edge at which wave_choice changes to 01.

For wave_choice 2'b10, triangle travel is downward immediately after reset and after any preceding edge in a non-10 choice. A downward step subtracts one modulo 32. Reaching 0 changes subsequent travel upward; an upward step adds one, and reaching 20 changes subsequent travel downward. Consequently, continuous triangle-mode pre-edge values after reset are 0, 31, 30, ..., 1, 0, 1, ..., 19, 20, 19, ... and repeat with a 40-rising-edge period after the initial 0-to-31 step. Changing into choice 10 applies the downward step to the existing wave value on that edge, without reinitialising wave.

For wave_choice 2'b11, wave becomes 0 on every rising clk edge.

Changing wave_choice does not itself change wave before the associated rising edge. Changing away from choice 00 restarts its cadence for a later return. Changing away from choice 10 establishes downward travel for a later return. Repeated rising edges repeatedly apply the currently selected rule. Because row k is sampled before its active edge, asynchronous reset assertion is visible in row k, while an ordinary choice-dependent update at row k's rising edge first appears in row k+1. Public-output updates occur only as stated here; there are no verification-visible observer bindings.
