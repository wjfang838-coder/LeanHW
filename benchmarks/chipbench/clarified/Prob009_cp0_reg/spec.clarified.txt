Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- clk: input 1 bit.
- rst: input 1 bit.
- we_i: input 1 bit.
- waddr_i: input [4:0].
- raddr_i: input [4:0].
- data_i: input [31:0].
- excepttype_i: input [31:0].
- int_i: input [5:0].
- current_inst_addr_i: input [31:0].
- is_in_delayslot_i: input 1 bit.
- data_o: output [31:0].
- count_o: output [31:0].
- compare_o: output [31:0].
- status_o: output [31:0].
- cause_o: output [31:0].
- epc_o: output [31:0].
- config_o: output [31:0].
- prid_o: output [31:0].
- timer_int_o: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

1. Module and ports



3. Reset

rst is active high and synchronous. A rising clk edge with rst asserted has priority over every write, interrupt, exception, and timer-match effect and sets count_o to 32'h00000000, compare_o to 32'h00000000, status_o to 32'h10000000, cause_o to 32'h00000000, epc_o to 32'h00000000, config_o to 32'h00008000, prid_o to 32'h004c0102, and timer_int_o to 1'b0. data_o is the exception: rst asserted forces it combinationally to 32'h00000000 without waiting for an edge. The reset edge also establishes the value retained by data_o as zero, so the first unlisted read address after reset release produces zero.

Before the first rising edge that samples asserted rst, count_o, compare_o, status_o, cause_o, epc_o, config_o, prid_o, timer_int_o, and the value retained by data_o for an unlisted address are unknown and shall be left uninitialized, with no declaration initializer or initial block. A pre-edge observation while rst is asserted still sees these preceding or power-up stored values, except that data_o is already forced to zero; the stored reset values first appear after that rising edge. If rst is low on the first subsequent rising edge, normal operation applies immediately.

4. Timing

Only a rising clk edge changes stored outputs: each pre-edge row observes old values, the edge captures enabled reset, write, interrupt, and exception effects, and the new values are observable immediately after that edge, while a static clk level and falling edges have no stored-output effect.

count_o, compare_o, status_o, cause_o, epc_o, config_o, prid_o, and timer_int_o are registered. An accepted change has one rising-edge capture latency: its pre-edge value is visible before the deciding edge and its new value is visible immediately afterward, with no additional pipeline cycle. data_o is combinational for reset and listed read addresses; post-edge changes of its selected registered output are visible immediately. For an unlisted read address, data_o retains its preceding value. timer_int_o is a retained level, not a pulse: once asserted it remains asserted for an unbounded number of cycles until a compare write or reset clears it.

The evaluated trace uses full-cycle rows. Row k denotes the observation before transition k, followed by transition k; it is a cycle count, not an implicit 10 ns clock. The interface supplies no step_ns or sample_offset_ns value, so this specification assigns no nanosecond period or sampling offset.

5. Behaviour

With rst low, we_i high at a rising edge enables the waddr_i-selected write, repeated asserted edges perform repeated writes, and we_i low performs none; reset has priority, exception effects may override the simultaneously written status_o bit 1 or epc_o, and a compare write clears timer_int_o.

When rst is low and we_i is high at a rising edge, waddr_i 5'b01001 writes all 32 data_i bits to count_o, 5'b01011 writes all 32 bits to compare_o and clears timer_int_o, 5'b01100 writes all 32 bits to status_o, 5'b01101 writes only cause_o bits 23, 22, 9, and 8 from the corresponding data_i bits, and 5'b01110 writes all 32 bits to epc_o. Every other waddr_i encoding writes none of these outputs. data_i has no effect unless such a write is enabled.

With rst low, raddr_i combinationally selects count_o, compare_o, status_o, cause_o, epc_o, prid_o, or config_o at addresses 5'b01001, 01011, 01100, 01101, 01110, 01111, or 10000 respectively, while an unlisted address retains the preceding data_o value; with rst high the address has no effect and data_o is zero.

On every non-reset rising edge, count_o increments modulo 2^32 unless an enabled write to 5'b01001 replaces it with data_i. compare_o retains its value except for an enabled write to 5'b01011. config_o and prid_o retain their values on every non-reset edge.

On every non-reset rising edge, int_i is copied into cause_o[15:10], including during a write or exception. An enabled cause write simultaneously replaces only cause_o[23], cause_o[22], cause_o[9], and cause_o[8]. All other cause_o bits retain their preceding values except for the exception fields specified below.

On a non-reset rising edge, excepttype_i 32'h00000001 sets status_o[1], sets cause_o[6:2] to 5'd0, and always captures an exception address. Values 32'h00000008, 32'h0000000a, 32'h0000000c, and 32'h0000000d set status_o[1] and set cause_o[6:2] to 5'd8, 5'd10, 5'd12, and 5'd13 respectively; they capture an exception address only if the pre-edge status_o[1] was clear. Value 32'h0000000e clears status_o[1]. Every other excepttype_i encoding causes none of these exception effects. Repeating a guarded exception while pre-edge status_o[1] is set updates its cause code but does not recapture the exception address.

When an exception address is captured, is_in_delayslot_i equal to one sets cause_o[31] and stores current_inst_addr_i minus 4 modulo 2^32 in epc_o; is_in_delayslot_i equal to zero clears cause_o[31] and stores current_inst_addr_i in epc_o. When no address capture occurs, current_inst_addr_i and is_in_delayslot_i have no effect. A qualifying capture overrides a simultaneous full epc_o write. A recognized exception or return overrides status_o bit 1 of a simultaneous full status_o write while every other status_o bit remains from data_i.

On a non-reset rising edge, timer_int_o becomes one when the pre-edge compare_o is nonzero and equals the pre-edge count_o. It otherwise retains its prior value. A simultaneous enabled write to compare address 5'b01011 clears timer_int_o with priority over a match; repeated later matches reassert it.
