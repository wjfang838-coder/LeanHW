Module and integration contract

Module: dig_stopwatch.
Ports below are in exact declaration order:
- clk: input 1 bit.
- reset: input 1 bit.
- start_stop: input 1 bit.
- seconds: output [5:0].
- minutes: output [5:0].
- hour: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
- integer CLK_FREQ: default = 50_000_000.
- Verification-visible signal `one_sec_pulse`: one_sec_pulse is asynchronously cleared by reset, is 1 during the cycle immediately following each CLK_FREQ-th accumulated rising clk edge with start_stop high, and is otherwise cleared on every reset-low rising clk edge, including paused edges; because a row is sampled before its active edge, assertion or clearing caused by that edge is observed in the following row.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

1. Module and ports.



3. Reset.

reset is active high and asynchronous. Whenever reset is asserted, seconds, minutes, hour, accumulated partial-second timing progress, and the verification-visible one_sec_pulse are immediately zero, regardless of clk or start_stop. Holding or repeatedly asserting reset keeps that cleared condition. If reset is asserted coincident with a rising clk edge, reset takes priority.

Deasserting reset causes no immediate change. The displayed value remains 0 hours, 0 minutes, and 0 seconds until later enabled rising clk edges complete an interval. The first such completed interval increments seconds to 1 under the ordinary counting law.

Before reset has ever been asserted, seconds, minutes, and hour have no established values. Reset-low clk and start_stop activity does not establish them. Assertion of reset exits this condition immediately and establishes all three displayed values as zero. This pre-first-reset unknown condition does not apply after reset has established the state.

4. Timing.

All stopwatch state changes occur on rising edges of clk, except that assertion of reset acts immediately and asynchronously. A falling edge, a steady clk level, or a change of start_stop without a rising clk edge has no effect.

With reset low and start_stop high, each rising clk edge contributes one count toward a one-second interval. Every CLK_FREQ-th accumulated enabled rising clk edge completes the interval and applies exactly one stopwatch tick. Paused edges do not contribute, and already accumulated partial progress is preserved across a pause. Thus a tick occurs after exactly CLK_FREQ enabled rising clk edges, which corresponds to one second when CLK_FREQ correctly denotes the input frequency.

seconds, minutes, and hour are registered outputs. A tick caused by a rising clk edge updates them for observation during the following clk cycle; otherwise they retain their prior values. Reset is the asynchronous exception and makes them zero immediately.

The verification-visible one_sec_pulse is asynchronously cleared by reset, is 1 for exactly one clk cycle immediately following every CLK_FREQ-th accumulated rising clk edge with start_stop high, and is cleared on every other reset-low rising clk edge, including paused edges. It is a one-input-clock-period pulse, not a continuous 1 Hz clock. Its advancement is independent of whether the displayed outputs have already reached their terminal value: enabled completed intervals continue to assert it after hour is 1, while the displayed time remains frozen.

For the evaluated autonomous Lean trace, row k denotes the settled observation at k times timing.step_ns, with any timing.sample_offset_ns applied as defined by the interface. A row samples outputs before that row's active-edge transition, and the resulting state is visible in the next row. This trace observation convention is separate from the physical circuit law: the actual stopwatch tick cadence is CLK_FREQ enabled rising clk edges and one_sec_pulse lasts one input-clock cycle. The supplied interface contains no numeric timing.step_ns or timing.sample_offset_ns values, so this document does not invent them.

5. Behaviour.

The deliverable shall be a SystemVerilog implementation of the digital stopwatch module dig_stopwatch. CLK_FREQ denotes the input clock frequency in hertz. It shall be an integer frequency strictly greater than 1 Hz; its default is 50,000,000 Hz. Behavior for settings outside that stated constraint need not be provided.

With reset low, start_stop high makes rising clk edges accumulate toward a completed interval and every CLK_FREQ-th accumulated enabled edge applies one stopwatch tick. start_stop low prevents accumulation and holds seconds, minutes, and hour while preserving partial timing progress, so a later high level resumes rather than restarts the interval. Reset overrides start_stop. Repeated high intervals continue counting; repeated low intervals remain paused. Because start_stop is one bit, 0 and 1 are its complete set of encodings.

On a completed enabled interval, if hour is 0 and seconds is less than 59, seconds becomes its pre-edge value plus one while minutes and hour hold. If hour is 0, seconds is 59, and minutes is less than 59, seconds becomes 0, minutes becomes its pre-edge value plus one, and hour holds. If hour is 0 and seconds and minutes are both 59, seconds and minutes both become 0 and hour becomes 1.

Asserting reset asynchronously makes seconds 0. After reset release, seconds remains 0 until the CLK_FREQ-th enabled rising clk edge; on each completed interval it increments unless its pre-edge value is 59, in which case it becomes 0. It holds between completed intervals, throughout pauses, and after hour is 1.

Asserting reset asynchronously makes minutes 0. Reset release causes no immediate change. On a completed enabled interval, minutes increments from its pre-edge value only when pre-edge seconds is 59 and pre-edge hour is 0, wrapping from 59 to 0. It holds on all other rising edges, throughout pauses, and after hour is 1.

Asserting reset asynchronously makes hour 0. Reset release causes no immediate change. hour changes to 1 only on a completed enabled interval whose pre-edge seconds and minutes are both 59 and whose pre-edge hour is 0. It otherwise holds through inactive edges, pauses, ordinary ticks, and all later completed intervals.

Once hour is 1, the displayed stopwatch is terminal at 1 hour, 0 minutes, and 0 seconds. Further completed intervals do not change seconds, minutes, or hour. Only reset clears the terminal value and permits the displayed stopwatch to restart; the independently specified one_sec_pulse continues to follow its own enabling and cadence law.
