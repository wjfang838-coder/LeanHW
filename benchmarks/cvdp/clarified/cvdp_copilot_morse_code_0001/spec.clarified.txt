The `morse_encoder` Verilog module translates 8-bit ASCII characters (`ascii_in [7:0]`) into Morse code. The output includes a 10-bit Morse code sequence (`morse_out [9:0]`) and a 4-bit length indicator (`morse_length [3:0]`). It employs a `case` statement for direct mapping and defaults to zero for unsupported inputs, ensuring immediate updates through combinational logic for real-time encoding 

---
Module Interface
Inputs:

- ascii_in [7:0]: Receives an 8-bit ASCII value, which specifies a character for Morse code encoding.

Outputs:

- morse_out [9:0]: Delivers the Morse code as a 10-bit binary sequence.
- morse_length [3:0]: Outputs the length of the Morse code sequence to indicate how many bits in morse_out are valid.
---
Module Functionality
Encoding Logic:

- Morse Code Encoding: Morse code is represented in binary, where a dot (.) is 0 and a dash (-) is 1.
- Binary Output: The morse_out register outputs the Morse code as a right-aligned binary sequence within a 10-bit field.
- Sequence Length: The morse_length register indicates the number of valid bits in the morse_out sequence, representing the actual length of the Morse code.
- Default Handling: If an ASCII input doesn’t match any predefined cases, both morse_out and morse_length are set to zero, indicating no valid Morse code output.
- Uppercase Only: The implementation explicitly handles uppercase ASCII characters (A to Z and 0 to 9).

1. Module and ports.

The module name is exactly morse_encoder. Its public boundary consists only of these ports, presented in the source-listed order:

ascii_in: input, 8 bits, spelled exactly ascii_in.
morse_out: output, 10 bits, spelled exactly morse_out.
morse_length: output, 4 bits, spelled exactly morse_length.

The confirmed integration contract uses named connections for ascii_in, morse_out, and morse_length. Neither the original requirements nor the integration answer establishes positional-instantiation order; therefore the presentation order above is not normative and morse_encoder must be instantiated by name. There are no public parameters.

3. Reset.

There is no reset input and no reset behavior. The module is combinational and has no state elements. From power-up, including before any reset edge has been seen (there can be none), both outputs are determined solely by the current ascii_in: a supported character produces its listed mapping and every unsupported value produces zero on both outputs. A change of ascii_in establishes the corresponding outputs without requiring a reset or clock edge.

4. Timing.

morse_out and morse_length are combinational with zero clock-cycle latency from ascii_in and update immediately when ascii_in changes. No quantitative propagation-delay limit is specified. There is no clock, pulse, periodic signal, circuit period, handshake, cancellation behavior, or retained result.

The worked-trace rows are observation samples of this autonomous combinational design. Row k denotes k times the interface step_ns after settling, with timing.sample_offset_ns applied. This observation convention is separate from circuit behavior and does not imply a 10 ns clock tick, circuit clock, period, or propagation-delay law.

5. Behaviour.

The implementation shall employ direct case mapping for the listed characters. Morse symbols are encoded in sequence order with dot equal to 0 and dash equal to 1. The resulting sequence is right-aligned in the 10-bit morse_out field and all unused high bits are zero. Leading dots are consequently leading zero bits within the valid low-order sequence. morse_length is the number of valid Morse symbols, from 1 through 5 for a supported character.

Whenever ascii_in is an ASCII uppercase letter A through Z or digit 0 through 9, both outputs select that character's mapping below, and every later assignment independently replaces the preceding selection. For each supported input, morse_out is the right-aligned 10-bit Morse sequence shown in the mapping table. For each supported input, morse_length is the number of Morse symbols shown in the mapping table. Every other one of the 256 possible 8-bit ascii_in values is unsupported; for each such value, morse_out is 0 and morse_length is 0.
