Module and integration contract

Module: JC_counter.
Ports below are in exact declaration order:
- clk: input 1 bit.
- rst_n: input 1 bit.
- Q: output [63:0].

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

1. Module and ports



3. Reset

rst_n is an active-low asynchronous reset. Whenever rst_n is low, Q is immediately forced to 64'h0000000000000000 regardless of clk, and every subsequent rising edge while rst_n remains low leaves it at that value. Reset assertion coincident with a rising clk edge has priority over the counter update.

At power-up, before rst_n has ever been asserted low, Q is unknown and remains unknown across rising clk edges. The implementation must leave Q uninitialised: it must have neither an initial block nor a declaration initialiser that gives it a definite value.

Releasing rst_n high does not itself change Q. On the first rising clk edge after release, Q changes from the reset value to 64'h8000000000000000; that result is observed after the edge. A later reset assertion immediately clears Q and restarts the same sequence.

4. Timing

Q is a registered output. While rst_n is high, it holds its value between rising clk edges and has a latency of one rising-edge step from its preceding value: each rising edge computes the next Q, which is visible immediately after that edge. Reset assertion is the sole asynchronous change.

The complete Q sequence has a period of 128 rising-clock cycles. Each bit of Q is high for 64 cycles and low for 64 cycles in every 128-cycle period, with phase determined by its bit position. There is no completion pulse and no terminal hold.

The evaluated full-cycle trace samples each row before that row's active edge. Thus the result produced by row k's edge first appears in row k+1. Row k denotes k full-cycle steps after settling; the interface specifies no numeric nanosecond step or sample offset. This observation convention is separate from the circuit law, whose update occurs on rising clk edges and whose asynchronous reset takes effect without waiting for an edge.

5. Behaviour

Inputs are interpreted at their declared one-bit widths. Therefore every possible input encoding is covered by the following rules.

Whenever rst_n is low, Q is asynchronously forced to 64'h0000000000000000 and remains at that value regardless of clk.

A rising clk edge updates Q by setting its next value to {~Q[0], Q[63:1]} when rst_n is high. A steady clk level and a falling clk edge have no effect. Repeated rising edges with rst_n high repeatedly apply this recurrence, and an intervening reset restarts it from zero.

rst_n is an active-low asynchronous reset: asserting it low immediately forces Q to zero, low holds Q at zero across any number of clk edges, assertion coincident with a rising clk edge has priority, and releasing it high does not itself change Q but permits the recurrence on the next and subsequent rising clk edges; any later assertion interrupts the sequence and restarts it from zero.

Q changes asynchronously to zero when rst_n is asserted low, otherwise holds between rising clk edges and updates at each rising edge with rst_n high to {~Q[0], Q[63:1]}. Because each trace row is sampled before its active edge, the value produced by that edge is first observed in the following row. After reset release the first such observed result is 64'h8000000000000000. The recurrence continues without a completion hold, returns to zero after 128 rising edges, and then repeats; any reset assertion clears and restarts it.
