Module and integration contract

Module: barrel_shifter.
Ports below are in exact declaration order:
- in: input [7:0].
- ctrl: input [2:0].
- out: output [7:0].

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

1. Module and ports



3. Reset

The module has no reset input and no state elements. From power-up onward, including before any edge has occurred, out is defined by the current in and ctrl values according to the behaviour below. There is no unknown initialization interval, reset assertion interval, or first step after reset release.

4. Timing

Out is combinational from the current in and ctrl inputs, with zero clock-cycle latency. Every change of either input immediately determines out after combinational settling. There are no pulses, periodic signals, circuit clock period, or circuit delay law.

The evaluated trace uses the interface's full-cycle observation convention only as a sampling convention for successive settled input rows; it does not imply a 10 ns clock tick or create a circuit period. The interface specifies neither timing.step_ns nor timing.sample_offset_ns, so no numerical elapsed-time scale or sampling offset is attached to those rows.

5. Behaviour

At all times and for every ctrl value from 3'b000 through 3'b111, in immediately determines out as the 8-bit unsigned logical right shift in >> ctrl, with zeros shifted into the most-significant positions. Thus ctrl=3'b000 passes in unchanged, while each nonzero unsigned ctrl value shifts by exactly its value from one through seven positions.

Changes to in and changes or repeated applications of ctrl act combinationally, without an inactive level, transaction state, interruption behavior, event priority, capture edge, hold or clear interval, completion, or restart sequence. Out continuously equals the current 8-bit value of in logically shifted right by the current unsigned ctrl value, and a sampled row observes the inputs present for that row with zero capture-to-observation latency.
