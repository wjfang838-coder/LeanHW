Module and integration contract

Module: clkgenerator.
Ports below are in exact declaration order:
- clk: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
-  PERIOD: default = 10.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

Module and ports



Reset

The module has no reset input and no reset behavior. At power-up, before any elapsed delay, `clk` is 1'b0, the same definite initial value on every execution. There is therefore no reset edge, reset assertion interval, or first step after reset release. No control can restart or alter the generator.

Timing

`clk` is an autonomous periodic output. It is initialized to 1'b0 at time zero and changes level after every `PERIOD/2` time units. Each low interval lasts exactly `PERIOD/2` time units and each high interval lasts exactly `PERIOD/2` time units; consequently, one complete low-plus-high cycle lasts `2 * (PERIOD/2)` time units. For the default `PERIOD = 10`, each level lasts 5 time units and a complete cycle lasts 10 time units.

The concrete normative trace below observes the default-parameter instance at `timing.step_ns = 1 ns` with `timing.sample_offset_ns = 0.001 ns`. Row k represents k ns after settling and reports the level before a toggle due at that row's transition; the changed level is observable immediately after that transition and therefore in the next row. This row cadence is only the observation convention. It is not an implicit 10 ns clock tick and does not replace the circuit law that `clk` toggles every `PERIOD/2` time units.

Behaviour

There are no input combinations or control modes. At time zero, `clk` is 1'b0. Number the successive half-period intervals starting at zero. Throughout every even-numbered half-period interval `clk` is 1'b0, and throughout every odd-numbered half-period interval `clk` is 1'b1. At the boundary after each successive `PERIOD/2` interval, `clk` toggles exactly once. This cadence continues forever and cannot be captured, held, cleared, completed, cancelled, paused, resumed, or restarted because the interface has no input that could request any such action.
