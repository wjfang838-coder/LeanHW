Module and integration contract

Module: comparator_3bit.
Ports below are in exact declaration order:
- A: input [2:0].
- B: input [2:0].
- A_greater: output 1 bit.
- A_equal: output 1 bit.
- A_less: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

Module and ports.



Reset.

The module has no reset input and no reset behavior. It has no state elements. From power-up onward, including before any edge has occurred, every output is defined solely by the current A and B values: A_greater, A_equal, and A_less have the values specified below. No output is uninitialized or unknown at power-up, and releasing or asserting reset is inapplicable.

Timing.

A_greater, A_equal, and A_less are combinational outputs with zero clock-cycle latency from both A and B. A change to either input immediately recomputes all three outputs using the current values of both inputs. There are no pulses, periodic outputs, clock, capture edge, observation edge, completion event, or retained result.

For the normative evaluated trace, row k is the settled combinational observation at k times the interface step duration; this sampling convention does not imply a 10 ns clock tick. The circuit itself has no clock period, cycle delay, or state-transition delay law.

Behaviour.

For every possible 3-bit input pair, A and B are interpreted as unsigned values from 0 through 7.

For every 3-bit A and B, A continuously participates as the unsigned left operand so changing A immediately recomputes the comparison results for the new A versus the current B; there are no modes or inactive level, simultaneous A/B changes use both new values, and there is no transaction, interruption, or history dependence.

For every 3-bit A and B, B continuously participates as the unsigned right operand so changing B immediately recomputes the comparison results for the current A versus the new B; there are no modes or inactive level, simultaneous A/B changes use both new values, and there is no transaction, interruption, or history dependence.

A_greater is continuously 1 exactly when the current unsigned 3-bit A is greater than the current unsigned 3-bit B and is otherwise 0, with no reset, capture or observation edge, latency, hold/clear interval, completion, restart, or retained state, so a pre-edge row observes the comparison of the values present before that edge.

A_equal is continuously 1 exactly when the current 3-bit A equals the current 3-bit B and is otherwise 0, with no reset, capture or observation edge, latency, hold/clear interval, completion, restart, or retained state, so a pre-edge row observes the comparison of the values present before that edge.

A_less is continuously 1 exactly when the current unsigned 3-bit A is less than the current unsigned 3-bit B and is otherwise 0, with no reset, capture or observation edge, latency, hold/clear interval, completion, restart, or retained state, so a pre-edge row observes the comparison of the values present before that edge.

Exactly one of A_greater, A_equal, and A_less is 1 for every input pair; the other two are 0. All input encodings are covered. Because operation is continuous and stateless, disabled inputs, transaction cancellation, first results, repeated starts, and retained data do not exist.
