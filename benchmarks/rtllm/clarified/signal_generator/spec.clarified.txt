Module and integration contract

Module: signal_generator.
Ports below are in exact declaration order:
- clk: input 1 bit.
- rst_n: input 1 bit.
- wave: output [4:0].

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

1. Module and ports.



3. Reset.

Reset is active low and asynchronous. Whenever rst_n is low, wave is 5'b00000 immediately, including when reset assertion coincides with a rising edge, and every state element is reset to the ascending direction with the stored waveform value zero. Rising edges while reset remains asserted retain those reset values.

Before reset has ever been asserted, wave is unknown. The implementation must leave its stored waveform state uninitialised, with no initial block or declaration initialiser that gives wave a defined power-up value.

Deasserting rst_n has no immediate effect. Wave remains 5'b00000 until the first rising edge after release; that edge changes wave to 5'b00001 and leaves the direction ascending. Any later reset assertion immediately clears and restarts the same sequence.

4. Timing.

Wave is a registered output updated only by rising edges of clk, except that asynchronous reset assertion forces it immediately to zero. With reset inactive, falling edges and steady clk levels have no effect. From deassertion of rst_n, wave has a one-rising-edge latency to the first nonzero value: the first rising edge produces wave = 1, which remains visible until the next rising edge.

The periodic sequence, counted in rising-edge intervals after reset release, is 0, 1, ..., 31, 31, 30, ..., 0, 0, 1, .... Its period is 64 rising-edge intervals: 32 intervals in the nondecreasing portion from the first 0 through the held 31, and 32 intervals in the nonincreasing portion from 30 through the held 0. Each endpoint is present for two consecutive pre-edge observations.

The evaluated trace uses full-cycle rows. Each row samples the settled output before its pending rising-edge transition, then advances the state once. Thus row k is observation k under the interface's full-cycle cadence; this observation convention is separate from the circuit law that only rising clk edges advance the waveform. The interface defines no numeric step_ns or sample_offset_ns values, so no physical nanosecond period or sampling offset is specified.

5. Behaviour.

While rst_n is high, only each rising edge of clk advances wave by one in its current direction or holds an endpoint for the edge that reverses direction, whereas falling edges and steady clk levels have no effect; while rst_n is low every rising edge retains wave at zero, simultaneous reset assertion takes priority, reset interruption restarts the progression, and repeated rising edges continue the endpoint-inclusive up/down sequence indefinitely.

Asserting rst_n low asynchronously forces wave to 5'b00000 in every phase and overrides a simultaneous rising clock edge, keeping wave zero through repeated rising edges while low; deasserting rst_n has no immediate effect, the next rising edge begins a fresh ascent to 5'b00001, and every later reset interruption or repeated assertion restarts or retains this reset condition.

Wave is unknown before any reset, becomes 5'b00000 immediately when rst_n is asserted, remains zero while reset is held and upon release until the first active rising edge, then is observed after successive rising edges as 1 through 31, holds 31 for the turn edge, falls through 30 to 0, holds 0 for the turn edge, and repeats without a completion interval; because each row is sampled before its active edge, a row reports the value produced by the preceding edge, and any reset assertion immediately clears and restarts this timing.

Equivalently, in the ascending direction a rising edge changes wave from any value 0 through 30 to wave + 1. At 31, the next rising edge leaves wave at 31 and changes the direction to descending. In the descending direction a rising edge changes wave from any value 31 through 1 to wave - 1. At 0, the next rising edge leaves wave at 0 and changes the direction to ascending. These laws cover every possible five-bit wave value in either direction.
