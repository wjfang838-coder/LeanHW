Module and integration contract

Module: square_wave.
Ports below are in exact declaration order:
- clk: input 1 bit.
- freq: input [7:0].
- wave_out: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

Module and ports.



Reset.

The module has no reset input or reset behavior. At power-up, before any rising edge has occurred, wave_out is 0 and the modulo-256 count of prior rising edges since initialization is 0. Both values are initialized to those definite values; wave_out is not unknown during this interval. The first rising edge applies the ordinary behavior stated below using that zero count and the freq value present at that edge.

Timing.

wave_out is registered. It changes only on a rising edge of clk and holds between rising edges, including during steady clk levels and falling edges. A qualifying rising edge toggles wave_out immediately after that edge; under the evaluated full-cycle observation convention, row k samples the settled value before the row's rising-edge transition, and the result of that transition first appears in row k+1. Each row therefore advances one clk cycle. The interface supplies no physical step_ns or sample_offset_ns, so the trace does not imply a 10 ns clock or any other physical period.

For a constant nonzero freq value N, wave_out holds each level for exactly N rising-edge cycles and therefore has a complete period of exactly 2N rising-edge cycles: N cycles low and N cycles high. Each high and low interval is thus specified as a count of cycles, not merely as a duty-cycle ratio. For freq equal to 0, wave_out never toggles, so it has no finite periodic-signal period and remains low if freq has been 0 since initialization.

Behaviour.

Only a rising edge of clk changes state. Every rising edge is processed once by the same law; a steady clk level and a falling edge have no effect.

The module maintains a modulo-256 count of prior rising edges since initialization or the most recent wave_out toggle. At each rising edge, the current 8-bit unsigned freq value is evaluated. If freq is nonzero and equals one plus that count, wave_out toggles and the count restarts at zero. Otherwise wave_out holds and the count advances by one modulo 256. Thus freq equal to 0 never causes a toggle, including when the count is 255.

Changing freq has no immediate effect between rising edges. At the next rising edge, the new freq value replaces the previous comparison target without clearing or restarting the existing count. This law applies to every change and every 8-bit freq encoding from 0 through 255.

wave_out begins at 0, holds across every nonqualifying edge, and toggles after every qualifying rising edge. After a toggle, the cadence restarts from count zero and repeats without a completion pulse, clear interval, disabled mode, transaction state, or separately retained result.
