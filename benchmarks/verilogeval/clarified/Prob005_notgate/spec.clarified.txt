Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- in: input 1 bit.
- out: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

Module and ports



Reset

The module has no reset input and no reset behavior. It has no stored state. At power-up, before any edge or other event, out is already the one-bit complement of the current in value; there is no uninitialized interval and no first-reset-edge condition.

Timing

The output out is combinational and continuously reflects the current in value with zero clock-cycle latency. There is no capture edge, observation edge, pulse, periodic output, state transition, or specified physical propagation delay.

Trace row k is an observation of the settled combinational result for that row's input before the model's vacuous transition. Full-cycle row spacing is an evaluation convention only; it does not specify a circuit clock period or delay law.

Behaviour

For every one-bit input value, out is the one-bit logical complement of in: when in is 1'b0, out is 1'b1; when in is 1'b1, out is 1'b0.

The input in continuously determines out as its one-bit complement; there are no modes, inactive controls, transactions, interruptions, retained values, or event-priority cases, so every change and every repeated value of in has the same immediate combinational effect.

The output out is continuously equal to the one-bit complement of the current in value, with no reset behavior, capture or observation edge, latency, hold or clear interval, completion phase, or restart.
