Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- in: input [15:0].
- out_hi: output [7:0].
- out_lo: output [7:0].

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

Module and ports



Reset

There is no reset and no stored state. From power-up onward, including before any observation step, both outputs are defined solely by the current input: out_hi equals in[15:8], and out_lo equals in[7:0]. Neither output has an unknown initialization interval.

Timing

Both outputs are combinational and have zero clock-cycle latency from in. There is no clocked capture, pulse, periodic output, hold interval, or completion event. In the evaluated trace, row k is observed at k times the interface step_ns after settling, with the interface sample_offset_ns applied; this observation convention does not impose a circuit clock, period, or delay law.

Behaviour

At all times, with no modes, reset, clock, transaction state, inactive level, or interruption behavior, in[15:8] continuously determines out_hi and in[7:0] continuously determines out_lo; simultaneous changes and repeated values have the same immediate combinational effect.

out_hi continuously equals in[15:8], with no reset assertion or release behavior, capture or observation edge, initialization, latency, hold or clear interval, completion, or restart; therefore a pre-edge row samples the input's current upper byte rather than an edge-captured result.

out_lo continuously equals in[7:0], with no reset assertion or release behavior, capture or observation edge, initialization, latency, hold or clear interval, completion, or restart; therefore a pre-edge row samples the input's current lower byte rather than an edge-captured result.

Equivalently, for every 16-bit value of in, out_hi is the unsigned quotient of in divided by 256, truncated to 8 bits, and out_lo is the unsigned remainder of in modulo 256, truncated to 8 bits. These laws cover every possible input encoding.
