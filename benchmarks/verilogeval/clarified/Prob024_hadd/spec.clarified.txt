Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- a: input 1 bit.
- b: input 1 bit.
- sum: output 1 bit.
- cout: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

Module and ports



Reset

There is no reset input or reset behavior and there are no state elements. From power-up onward, including before any edge has occurred, sum and cout are defined directly by the current values of a and b; neither output has an uninitialized interval.

Timing

sum and cout are combinational outputs with zero clock-cycle latency from a and b. The module has no clock, capture edge, pulse, periodic signal, circuit period, or delay law. Trace row k is an observation at k times the interface step interval after settling, at the interface sample offset; this observation convention does not imply a 10 ns clock tick or any circuit period.

Behaviour

Inputs a and b continuously participate in unsigned one-bit addition. The sum output is continuously a XOR b. The cout output is continuously a AND b.

Equivalently, when a is 0, sum equals b and cout is 0; when a is 1, sum is the complement of b and cout equals b. When b is 0, sum equals a and cout is 0; when b is 1, sum is the complement of a and cout equals a. Thus the complete cases are: inputs 00 produce sum 0 and cout 0; inputs 01 produce sum 1 and cout 0; inputs 10 produce sum 1 and cout 0; and inputs 11 produce sum 0 and cout 1.

Every input change, including simultaneous changes and repeated combinations, is reflected combinationally. There is no mode, stored state, capture, interruption, initialization phase, hold or clear interval, completion phase, cancellation, disabled-input mode, transaction, or restart behavior. Under pre-transition row semantics, each row observes the combinational result of the input values present for that row.
