Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- d: input 1 bit.
- ena: input 1 bit.
- q: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

1. Module and ports



3. Reset

There is no reset input and no reset behavior. Consequently, reset polarity, synchronous or asynchronous reset timing, a reset value, a first reset edge, and a first step after reset release do not apply.

At power-up, before any interval in which ena has been asserted, q is unknown regardless of d. The held value is likewise uninitialised at power-up. The implementation must leave this state uninitialised: it must not give it a declaration initialiser or an initial-block value. Once ena has been asserted, the power-up unknown is replaced by the behavior specified below.

4. Timing

q is a level-sensitive output, not an edge-triggered registered output. Whenever ena is asserted, q follows the current d immediately, with zero clock-cycle latency and without waiting for an edge. Whenever ena is deasserted, q holds the value present at the instant of deassertion. There is no capture edge, clock, completion pulse, periodic output, transaction latency, or fixed circuit period.

For the evaluated trace, row k denotes observation step k after the inputs and level-sensitive output have settled. The interface provides no numeric step duration or sample offset, and a row must not be interpreted as an implicit 10 ns clock tick. This trace observation convention is separate from the circuit law above, which specifies immediate level-sensitive response and no clock period or edge delay.

5. Behaviour

Inputs and outputs are interpreted at their declared one-bit widths, so the cases below cover every input encoding.

At power-up before any interval with ena asserted, q is unknown regardless of d.

Whenever ena is asserted, q equals the current value of d and follows every change of d without waiting for an edge.

While ena is deasserted, q retains the value it most recently had while ena was asserted, so changes of d have no effect.

While ena is asserted, every initial, simultaneous, interrupted, or repeated change of d is reflected immediately at q, whereas while ena is deasserted d has no effect and q retains its prior value until ena is asserted again.

Asserting ena makes q immediately equal to the current d and remain responsive to d, while deasserting ena makes q retain its value at that instant; repeated assertions restart this transparent behavior and simultaneous changes produce q equal to the resulting d while ena is asserted.

There is no reset, capture edge, completion, or fixed transaction latency: q is initially unknown, becomes equal to d immediately whenever ena is asserted, and retains its last such value while ena is deasserted, so a pre-edge row observes that current transparent-or-held value and an active edge itself causes no change.
