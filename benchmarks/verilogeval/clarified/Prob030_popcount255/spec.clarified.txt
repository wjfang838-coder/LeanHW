Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- in: input [254:0].
- out: output [7:0].

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

Module and ports



Reset

There is no reset input and no reset behavior. The module has no state elements. From power-up, including the first observation before any edge has occurred, out is defined as the population count of the input value currently present; it is never an uninitialized stored value.

Timing

out is combinational with zero clock-cycle latency from in. It continuously reflects the settled current value of in. There are no pulses, periodic circuit signals, capture edges, hold intervals, or completion phases.

The evaluated trace uses the interface observation cadence: row k denotes the settled sample at k * timing.step_ns, taken using timing.sample_offset_ns. This sampling convention does not impose a clock period or a propagation-delay law on the combinational circuit.

Behaviour

At all times, with no modes or inactive level, every bit of the 255-bit input in contributes one when it is 1 and zero when it is 0. Simultaneous input changes immediately recompute the result as the unsigned sum of all bits in[254:0]. There is no transaction state, interruption behavior, or distinction for repeated values.

The 8-bit output out continuously equals the population count of the current 255-bit input. Equivalently, out is the sum of the 255 individual bit values in[0] through in[254]. Its complete mathematical range is 0 through 255, which is represented exactly by out[7:0]. This law applies to every possible 255-bit input encoding.

There is no reset, capture edge, observation-edge latency, hold or clear interval, completion phase, or restart phase. Therefore a row sampled before any edge observes the count for the input present before that edge, including the first observation and every subsequent input change.
