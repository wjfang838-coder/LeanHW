Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- clk: input 1 bit.
- d: input [7:0].
- q: output [7:0].

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

1. Module and ports



2. Reset

There is no reset input and no reset operation. At power-up, before any rising edge of clk has occurred, q is 8'h00 regardless of d. Because reset does not exist, reset assertion, a first reset edge, and reset release do not occur; the first state transition is the first rising edge of clk, which captures d in the same way as every later rising edge.

3. Timing

q is a registered output. On a rising edge of clk it captures the contemporaneous 8-bit value of d, and the captured value becomes observable after that edge. Equivalently, under the normative pre-edge sampling convention used by the worked trace, row k displays the value captured at the preceding rising edge, so the capture made by row k's edge first appears in row k+1. The latency from the named input d at a rising edge to the corresponding sampled q is one trace row, or one clock cycle under this convention.

Each trace row represents one full-cycle observation: row k is sampled at k * step_ns after settling, using the interface's sample_offset_ns within that step. This observation cadence is distinct from a physical delay law. The circuit performs one capture per rising-edge-to-rising-edge clock cycle; no absolute clock period or propagation delay is specified.

q is not a pulse or periodic waveform generated by the module. It holds its captured value through all steady clock levels and falling edges until the next rising edge.

4. Behaviour

Every rising edge of clk captures the contemporaneous 8-bit d value into q. A steady clk level and every falling edge have no effect. Successive rising edges perform successive captures without a busy mode, interruption condition, completion phase, or restart phase.

d affects q only through its complete 8-bit value at a rising edge of clk. Changes to d between rising edges have no immediate effect. If d changes coincident with a rising edge, the new contemporaneous 8-bit value is the value captured at that edge. Every later rising edge samples d again, for every one of the 256 possible input encodings.

q starts at 8'h00 with no reset input, changes after each rising edge of clk to the d value captured at that edge, and holds that value through all intervening levels and falling edges until the next rising edge. Under pre-edge row sampling, the newly captured value first appears in the following row, and capture repeats indefinitely without completion or restart phases.
