Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- clk: input 1 bit.
- reset: input 1 bit.
- q: output [9:0].

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

1. Module and ports



2. Reset

reset is active high and synchronous. It is sampled only on a rising edge of clk. When reset is high at a rising edge, q becomes 10'h000; continued assertion makes q 10'h000 again on every rising edge. Changes of reset between rising edges have no immediate effect. Assertion interrupts counting at the next rising edge, and a rising edge simultaneous with assertion or deassertion uses the reset level present at that edge.

At power-up, before any rising edge has sampled reset high, q is unknown. The implementation must leave q's stored value uninitialised: it must not give it a declaration initialiser or an initial-block value. Rising edges with reset low do not make this initially unknown value known. The first rising edge that samples reset high makes q known as 10'h000. On the first rising edge after reset is released, normal counting applies, so q becomes 10'h001; because rows observe the pre-edge value, that value appears in the following row.

3. Timing

q is a registered output. Only a rising transition of clk updates it; falling edges and steady clock levels have no effect. Each rising edge samples reset and the pre-edge q. q holds between rising edges. From a rising edge that samples reset high, the registered zero is visible after that edge and in the following pre-edge-sampled row. From the first rising edge that samples reset low after reset, 10'h001 is visible after that edge and in the following row. There are no pulse or independently periodic outputs.

The normative trace uses full-cycle observations: each row samples q before the active rising-edge transition, and then that transition computes the state observed by the next row. This observation convention is separate from the circuit's clock period and propagation delay, neither of which is numerically specified.

4. Behaviour

At each rising edge, if reset is high, q becomes 10'h000. Otherwise, if q has previously been made known by a reset edge, pre-edge q equal to 10'd999 makes q become 10'h000, and every other reachable pre-edge value makes q become the pre-edge value plus 10'd1. This is a modulo-1000 count over 0 through 999 inclusive. Repeated rising edges repeat this update law. Repeated reset edges keep q at zero, and counting restarts from zero after release.

Before the first rising edge that samples reset high, q remains unknown even across rising edges with reset low. Once reset has made q known, it remains known and retains its last registered value between rising edges.
