Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- clk: input 1 bit.
- in: input 1 bit.
- out: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

Module and ports



Reset

There is no reset input or reset operation. At power-up, before any clock edge, out is 0; this is the same definite initial value regardless of the input in. Because reset does not exist, reset assertion, a first reset edge, and a first step after reset release are not applicable. The sole stored one-bit state represented by out has the power-up value 0.

Timing

out is registered. On every rising edge of clk it is updated from the value of in sampled at that edge and the preceding value of out. The update becomes observable immediately after that edge; under the normative pre-edge trace convention it first appears in the next row, a latency of one clock cycle (one trace row) from the sampled input. out holds between rising edges. There are no pulses or periodic outputs specified by this module.

One SpecIR full-cycle step denotes one rising edge of clk. Row k samples the settled pre-edge output before edge k and is separated from row k+1 by one full clock cycle. If the interface supplies step_ns and sample_offset_ns, row k denotes k times step_ns after settling, sampled at the stated offset; it never implies a 10 ns clock tick. This observation convention does not set the circuit's physical clock period or propagation delay, neither of which is specified.

Behaviour

out starts at 0 without a reset input, is replaced immediately after every rising edge by the value of in at that edge XOR its pre-edge value, and otherwise holds indefinitely; because row k is sampled before its active edge, row 0 observes the initial 0 and the result captured at row k's edge is first observed at row k+1, with every edge completing one update and the next edge immediately able to update again.

Only a low-to-high transition of clk updates out, atomically replacing it with the value of in at that edge XOR the preceding out; steady low, steady high, and falling edges have no effect, every rising edge performs the same update with no busy mode or interruption state, and consecutive rising edges repeatedly apply it.

The value of in present at each rising edge of clk is applied exactly once: 1'b0 preserves the preceding out and 1'b1 complements it; changes to in between rising edges have no effect, and values presented on consecutive rising edges are applied independently with no transaction, interruption, or inactive mode.

Thus the complete one-bit input cases at a rising edge are: in equal to 0 leaves out unchanged, and in equal to 1 complements out. Since in is one bit, there are no additional input encodings. There is no disabled mode, transaction cancellation, retained-result mode distinct from ordinary holding, or completion indication.
