1. Module and ports.



3. Reset.

There is no reset input and no reset behavior. The module has no state elements. At power-up, including before any edge has occurred, f is already the defined combinational value selected from the current inputs: f = x2 when x3 is 0, and f = x1 when x3 is 1. Because there is no reset or stored state, a first step and every later step leave this rule unchanged.

4. Timing.

The output f is combinational, with zero clock-cycle latency from x3, x2, and x1. It has no capture edge, registered delay, pulse width, period, or duty cycle. Changes to any input are reflected by evaluating the selector law on the current input values.

For the normative worked trace, row k is an observation after settling at the kth full-cycle sampling step. A row samples the current combinational output before the abstract step transition. The object has no state transition, and neither a physical circuit period nor a propagation-delay law is specified; the trace's observation cadence does not impose either one.

5. Behaviour.

For every possible combination of the three one-bit inputs, f = x3 ? x1 : x2. Equivalently, when x3 is 0, f equals x2; when x3 is 1, f equals x1.

The input x3 selects the controlling data input: changing x3 changes f exactly when x1 and x2 differ, and simultaneous input changes are resolved from the current values with no history.

The input x2 directly determines f when x3 is 0 and has no effect when x3 is 1, when f equals x1.

The input x1 directly determines f when x3 is 1 and has no effect when x3 is 0, when f equals x2.

The output f is continuously the combinational value x3 ? x1 : x2, with no reset behavior, capture or observation edge, initialization, latency, hold or clear interval, completion, restart, mode, transaction, interruption, or retained result.
