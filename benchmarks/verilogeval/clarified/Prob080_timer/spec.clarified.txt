Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- clk: input 1 bit.
- load: input 1 bit.
- data: input [9:0].
- tc: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

Module and ports



Reset

There is no reset input and no reset event. At power-up, before the first rising clock edge that captures an asserted load, tc is unknown and must remain uninitialised: the implementation must provide neither an initial block nor a declaration initialiser that gives the countdown state or tc a defined value. A rising edge with load deasserted does not make this unknown state valid. The first rising edge with load asserted captures data; immediately after that edge, tc is 1 if the captured value is zero and is 0 otherwise.

Timing

All state changes occur only on a rising edge of clk. Steady clock levels and falling edges have no effect. tc is a registered output derived from the most recently captured and subsequently updated countdown value. A load capture or countdown update at one rising edge is visible immediately after that edge; under the normative trace convention, which samples before each active edge, it first appears in the following row, a latency of one trace row from the sampled input.

When a nonzero countdown reaches zero, tc becomes 1 and remains continuously asserted until a later rising edge captures a nonzero value. It is therefore a retained level, not a fixed-width pulse. The specification imposes no physical clock period or propagation delay. The full-cycle trace advances by the interface time step per row: row k denotes k times that step after settling; this observation convention does not imply a 10 ns clock or any circuit delay law.

Behaviour

Only a rising edge of clk changes the countdown state: at each such edge an asserted load starts or restarts the countdown from data with priority over countdown progress, while a deasserted load advances a nonzero countdown by one toward zero and leaves a completed countdown at zero; steady clk levels and falling edges have no effect, and repeated rising edges repeat this rule.

When load is asserted at a rising clk edge, that edge starts or restarts the countdown from data regardless of whether a prior countdown is active or complete; when load is deasserted, the edge instead advances a nonzero countdown by one toward zero or retains completion, and load changes away from a rising edge have no effect.

Data is sampled as the new 10-bit countdown value only on a rising clk edge at which load is asserted, including every restart; otherwise data has no effect, whether the countdown is active or complete.

There is no reset input, so tc is unknown before the first loaded value is captured; tc is 1 exactly while the most recently loaded 10-bit value, reduced by one on each subsequent rising clk edge while nonzero, has reached zero, so loading zero makes it 1 immediately after that capture edge, loading a nonzero value makes it 0 immediately after that edge, the edge reducing one to zero makes it 1 immediately afterward, completion is retained until a later load of a nonzero value clears it, and because each table row is sampled before its active edge every capture or countdown result first appears in the following row.

Input widths govern all encodings. load is one bit, so its complete set of hardware values is deasserted 0 and asserted 1. data is an unsigned 10-bit value from 0 through 1023. Loading 0 completes immediately. Loading N from 1 through 1023 makes tc 0 after the load edge, then each later rising edge with load deasserted reduces the retained value by one; the edge performing the Nth such reduction reaches zero and makes tc 1. An asserted load always cancels and replaces any active or completed countdown with the newly sampled value.
