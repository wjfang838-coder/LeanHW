Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- clk: input 1 bit.
- a: input 1 bit.
- q: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

1. Module and ports.



3. Reset.

There is no reset input and no reset operation. At power-up, before the first positive edge of clk has occurred, q is unknown. The implementation must leave q's stored state uninitialised: it must not give that state a declaration initialiser or an initial-block value. The first positive edge samples a and makes q the one-bit complement of that sampled value immediately after the edge. Thus there is no distinct reset-release step or reset value.

4. Timing.

q is a registered output. Every positive edge of clk samples a; q becomes the complement of that sampled a immediately after the edge and holds that value until the next positive edge. A trace row sampled before an edge therefore shows the value retained from the preceding positive edge. Changes of a at any other time have no immediate effect. There are no pulses or autonomous periodic outputs.

The circuit's clock period is 10 ns in the supplied waveform, consisting of 5 ns with clk low and 5 ns with clk high. Its functional law is edge based and imposes no additional propagation delay beyond becoming observable after the edge.

For the evaluated full-cycle trace, row k is the settled observation at k times the interface step duration; it is not assigned an implicit 10 ns timestamp. This observation convention is separate from the 10 ns clock period shown by the original waveform.

5. Behaviour.

Before the first rising edge q is unknown. On every rising transition of clk, for every one-bit value of a, q becomes its one-bit complement: sampled a = 0 produces q = 1, and sampled a = 1 produces q = 0.

Low clock levels, high levels without a transition, and falling transitions do not change q. Every repeated rising transition independently replaces q using the value of a sampled on that edge. Changes to a between rising edges have no immediate effect; they affect q only if and when a later rising edge samples them. q retains its last registered value through every non-rising interval. There is no completion, restart, cancellation, or transaction phase.
