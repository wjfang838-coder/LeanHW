Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- clk: input 1 bit.
- j: input 1 bit.
- k: input 1 bit.
- areset: input 1 bit.
- out: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
-  A: default = 0.
-  B: default = 1.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

Module and ports



Reset

areset is an active-high asynchronous reset. Whenever areset is asserted high, out is asynchronously forced to 0 regardless of clk, j, or k; continued assertion keeps it 0, deassertion alone leaves it 0, and after release only a later rising clk edge can apply the j/k rule, with reset taking priority if asserted at that edge.

At power-up, before reset has ever been asserted or a rising edge has established a state, out is unknown and must remain uninitialised: it has no initial block or declaration initialiser. From this unknown power-up state, a rising edge with areset low establishes ON for j=1 and k=0, establishes OFF for j=0 and k=1, and leaves out unknown for j=k. Assertion of reset always establishes OFF.

Timing

out is a Moore-state output. Apart from asynchronous reset assertion, it changes only immediately after a rising edge of clk and retains the resulting value between rising edges. In the pre-edge sampled full-cycle trace, the update has a latency of one clock cycle from the j or k value sampled at a rising edge: that row shows the retained prior value, and the next row shows the update. There is no completion pulse or terminal interval, and every later rising edge may update out again.

In the evaluated trace, row k denotes k times the interface step duration after settling, and sampling uses the interface sample offset. A full-cycle step represents successive active rising edges; it is not an implicit 10 ns clock tick. This trace observation convention is separate from the circuit law that only rising edges update state and that reset assertion acts asynchronously.

Behaviour

The two established states are OFF, for which out is 0, and ON, for which out is 1.

Only a rising edge of clk can update out while areset is low: that edge applies the j/k rule from the pre-edge out value, whereas a steady clk level or falling edge has no effect, repeated rising edges each perform a new update, and an areset assertion coincident with a rising edge forces out to 0 instead.

With areset low, j is sampled only on rising clk edges and sets out to 1 exactly when the pre-edge out is 0 and j is 1; j has no effect when pre-edge out is 1 or away from a rising edge, j=0 preserves out=0, repeated samples apply independently, and asserted areset overrides j and forces out to 0.

With areset low, k is sampled only on rising clk edges and clears out to 0 exactly when the pre-edge out is 1 and k is 1; k has no effect when pre-edge out is 0 or away from a rising edge, k=0 preserves out=1, repeated samples apply independently, and asserted areset overrides k and forces out to 0.

Thus, on each rising edge with areset low, OFF changes to ON when j is 1 and otherwise remains OFF; ON changes to OFF when k is 1 and otherwise remains ON. In OFF, k is irrelevant. In ON, j is irrelevant. This completely covers all four j/k encodings in either established state.

out is forced to 0 immediately when areset is asserted and remains 0 through release until changed by a rising clk edge; each pre-edge row observes the result retained from the preceding reset or rising edge, and immediately after a rising edge with areset low out becomes 1 from pre-edge 0 when j=1, becomes 0 from pre-edge 1 when k=1, or otherwise holds, with no separate completion interval so every later rising edge can update it again.
