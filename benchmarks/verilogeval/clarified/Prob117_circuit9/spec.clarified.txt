Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- clk: input 1 bit.
- a: input 1 bit.
- q: output [2:0].

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

1. Module and ports.



3. Reset.

TopModule has no reset input and no reset behavior. Its only stored value, q, is unknown at power-up before any rising edge has occurred. The implementation must leave q uninitialised: it must not give q a declaration initialiser or an initial-block value. The first rising edge samples a and applies the behavior below. Thus a sampled 1 makes q equal 3'b100 after that edge; a sampled 0 while q is still unknown leaves q unknown. There is no reset-release step.

4. Timing.

q is a three-bit registered output updated only on a rising transition of clk. A stationary high or low clk and a falling transition do not update it. Each rising edge samples a and the pre-edge q, and the resulting q is observable during the following cycle, a latency of one clock cycle from a. A simultaneous change of a is governed by the value sampled at that rising edge. q retains its resulting value between rising edges. There is no completion pulse or periodic output.

For the evaluated SpecIR trace, each row is sampled before its pending rising-edge transition and each step represents one complete clock cycle. With the interface timing convention, row k denotes k * step_ns after settling, with the sample taken at sample_offset_ns within that step. This observation convention does not impose a 10 ns clock tick. The circuit law itself is edge-based and does not specify an absolute clock period or propagation delay.

5. Behaviour.

At every rising edge of clk, if a is 1, q becomes 3'b100 regardless of its prior value. Repeated rising edges sampling a as 1 repeatedly produce 3'b100.

At every rising edge of clk, if a is 0 and the pre-edge q is 3'b110, q becomes 3'b000. If a is 0 and the pre-edge q is any other known three-bit value, q becomes that value plus 3'b001 modulo eight. If a is 0 while q is unknown, q remains unknown.

Changes of a away from a rising edge have no effect. A later sampled value of a supersedes the earlier choice. Every rising edge immediately applies the same rule, including repeated rising edges; there is no separate completion, clear, cancellation, disabled, or restart interval.
