1. Module and ports.



3. Reset.

There is no reset and no stored state. Consequently, there is no reset edge, reset-release step, or power-up initialization interval affecting the output. From power-up onward, `out` is determined solely by the current values of `a`, `b`, `c`, and `d` according to the behavior below.

4. Timing.

`out` is combinational. A change to any of `a`, `b`, `c`, or `d` affects `out` with zero clock-cycle latency. There are no pulses, periodic outputs, capture edges, observation edges, transactions, completion events, or retained values.

5. Behaviour.

For every possible combination of the four one-bit inputs, `out = a ^ b ^ c ^ d`. Thus `out` is 1 exactly when an odd number of inputs are 1, and is 0 exactly when an even number are 1.

Equivalently, when `a = 0`, `out = b ^ c ^ d`, and when `a = 1`, `out = ~(b ^ c ^ d)` within one bit. When `b = 0`, `out = a ^ c ^ d`, and when `b = 1`, `out = ~(a ^ c ^ d)` within one bit. When `c = 0`, `out = a ^ b ^ d`, and when `c = 1`, `out = ~(a ^ b ^ d)` within one bit. When `d = 0`, `out = a ^ b ^ c`, and when `d = 1`, `out = ~(a ^ b ^ c)` within one bit.

Changing exactly one input while holding the other three fixed complements `out`. More generally, simultaneous changes to an odd number of inputs complement `out`, while simultaneous changes to an even number leave `out` unchanged. There are no modes, disabled-input conditions, transactions, cancellations, repeated starts, first-result distinctions, completion states, or retained data.
