1. Module and ports.



3. Reset.

There is no reset input and no state. Consequently there is no asserted-reset interval, reset edge, reset-release step, or state element requiring a reset value. At power-up, before any hypothetical reset edge, `q` already reads the combinational value selected by the current `a`; this is the same behavior at all later times. No initialized storage is part of the specification.

4. Timing.

The output `q` is combinational from the current input `a`, with zero clock-cycle latency. There is no clock, registered output, pulse, periodic signal, circuit period, or sequential delay law.

For the evaluated trace of this autonomous design, row k denotes the settled observation at k times the interface's `step_ns`, with the interface's `sample_offset_ns` convention applied; it does not imply a 10 ns clock tick. This interface supplies no numeric `step_ns` or `sample_offset_ns`, so this document does not invent either value. This trace observation convention is separate from the circuit behavior: the circuit itself is combinational and has no period.

5. Behaviour.

For every current value of `a`, the current value of `q` is selected by this complete law: 0 gives 16'h1232, 1 gives 16'haee0, 2 gives 16'h27d4, 3 gives 16'h5a0e, 4 gives 16'h2066, 5 gives 16'h64ce, 6 gives 16'hc526, and 7 gives 16'h2f19.

The output `q` is a purely combinational function of the current `a`; it has no capture edge, latency, hold or clear interval, completion condition, restart behavior, or dependence on any earlier input. All eight possible 3-bit input encodings are covered. Repeating a value or changing directly between any two values simply selects the mapping for the current value; there is no inactive or disabled encoding and no transaction to cancel or retain.
