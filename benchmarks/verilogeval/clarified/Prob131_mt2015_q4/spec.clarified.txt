Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- x: input 1 bit.
- y: input 1 bit.
- z: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

Module and ports



Reset

There is no reset input and no reset behavior. The design has no state elements. From power-up onward, including before any observation step has occurred, z has the definite combinational value x OR NOT y. There is no first reset edge and no first-step state change.

Timing

z is combinational and continuously reflects the current x and y inputs with zero clock-cycle latency. There is no clock, capture edge, registered output, pulse, periodic signal, transaction, or specified propagation delay.

The evaluated trace uses the interface observation convention independently of the circuit timing law: row k denotes k * 1 ns after settling, and sampling uses the interface offset of 0.001 ns. The 1 ns row spacing is not an implicit circuit clock tick and does not impose a circuit period or delay.

Behaviour

For every input combination, z continuously equals x OR NOT y. Equivalently, x=1 forces z=1; when x=0, z equals NOT y. Also equivalently, y=0 forces z=1; when y=1, z equals x. Thus z=0 only for x=0 and y=1, and z=1 for x=0,y=0; x=1,y=0; and x=1,y=1.

Changes to either input, simultaneous changes, interruptions, and repeated input patterns have this same immediate effect. There is no reset, transaction state, capture or observation edge, initialization interval, latency, retained value, hold or clear interval, completion pulse, cancellation, or restart. Each trace row observes the value determined by the inputs present for that row.
