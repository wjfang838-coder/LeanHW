Module and integration contract

Module: TopModule.
Ports below are in exact declaration order:
- clk: input 1 bit.
- x: input 1 bit.
- y: input [2:0].
- Y0: output 1 bit.
- z: output 1 bit.

Public parameters (preserve names, defaults and symbolic port ranges):
- None.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. Describe transaction latency from the accepting edge, and distinguish the completion pulse from the interval during which result data remains valid.

1. Module and ports



3. Reset

There is no reset. The module has no state elements and neither output has an initialization event. From power-up onward, including before any clock edge, each output is the continuously evaluated function of the current x and y inputs stated below. Thus, for y from 3'b000 through 3'b100, both outputs have their stated definite values immediately; for y from 3'b101 through 3'b111, both outputs are unknown for as long as that input encoding is present. No initial block or declaration initializer may replace those declared unknown results with definite values.

4. Timing

Y0 and z are combinational outputs with zero clock-cycle latency. Y0 responds continuously to x and y. z responds continuously to y and is independent of x for listed y encodings; for unlisted encodings its value is unknown. clk has no effect at either level or on either edge, including during simultaneous input changes and repeated activity. There are no pulses, periodic output signals, captures, holds, clears, transactions, cancellation behavior, retained results, or completion/restart intervals.

The evaluated trace uses full-cycle observation steps: row k denotes the kth configured observation step after settling, and each row samples the outputs from that row's current inputs before the model advances. This is only an observation convention. The circuit has no clock-dependent period and the specification imposes no physical propagation-delay law.

5. Behaviour

At all times, x selects Y0 as follows: for y=3'b000 or 3'b010, Y0 equals x; for y=3'b001, 3'b011, or 3'b100, Y0 equals the complement of x; and for y=3'b101 through 3'b111, Y0 is unknown, with every x change taking effect combinationally and no inactive level, capture, interruption, or transaction history.

At all times, y selects the combinational results: Y0 equals x for y=3'b000 or 3'b010, equals the complement of x for y=3'b001, 3'b011, or 3'b100, and is unknown for y=3'b101 through 3'b111; z is 1'b0 for y=3'b000 through 3'b010, 1'b1 for y=3'b011 or 3'b100, and unknown for y=3'b101 through 3'b111, with every y change taking effect without capture, interruption, or transaction history.

Y0 is continuously combinational with no reset or initialization: it equals x for y=3'b000 or 3'b010, equals the complement of x for y=3'b001, 3'b011, or 3'b100, and is unknown for y=3'b101 through 3'b111, so a pre-edge row observes the value from the inputs present before that edge and there is no capture-to-observation latency, hold, clear, completion, or restart interval.

z is continuously combinational with no reset or initialization: it is 1'b0 for y=3'b000 through 3'b010, 1'b1 for y=3'b011 or 3'b100, and unknown for y=3'b101 through 3'b111, so a pre-edge row observes the value from y present before that edge and there is no capture-to-observation latency, hold, clear, completion, or restart interval.

For every x when y is 3'b101, 3'b110, or 3'b111, Y0 is unknown. For every x when y is 3'b101, 3'b110, or 3'b111, z is unknown.
