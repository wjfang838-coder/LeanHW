Module: TopModule.

Event convention: row k drives input i[k], waits for combinational settling and observes out(s[k], i[k]) BEFORE the active clock edge specified by the behavioral rules below. Use those rules for clock polarity and reset sensitivity. That edge produces s[k+1] = step(s[k], i[k]). A register assigned input i[k] at that edge is visible in row k+1; this is ONE register, not an input register plus an output register. Asynchronous reset assertion takes effect without waiting for that edge. 1. Module and ports



3. Reset

areset is active high and asynchronous. While areset is asserted, the seven-bit global branch history register is 7'b0000000 and all 2**n two-bit PHT states are LNT (2'b01); reset overrides simultaneous prediction and training activity. With predict_valid asserted during reset, predict_taken is 1'b0 and predict_history is 7'b0000000. With predict_valid deasserted, both outputs are unknown even while reset is asserted.

At power-up, before areset has ever been asserted, the global branch history and every PHT state are uninitialized. Therefore predict_history is unknown, and predict_taken is unknown because either the current history or the selected PHT state is unknown. The implementation must leave this state uninitialized, with no initial block or declaration initializer. When predict_valid is low, both outputs are unknown independently of this power-up state.

After areset is released, the reset values remain until a qualifying rising edge changes them. Outputs respond immediately to the released reset level: a valid prediction uses the retained reset state with no extra latency. At the first rising edge after release, training and prediction perform exactly the updates stated below; if neither qualifying update applies, every state element retains its reset value.

4. Timing

All sequential changes occur only on a rising edge of clk, except that assertion of areset takes effect asynchronously. Low clk levels and falling edges cause no state change. Repeated rising edges repeat all input-qualified updates, and areset takes precedence over clk.

predict_taken is combinational when predict_valid is high: it responds immediately to predict_pc, the current global history, and the currently selected PHT state. A PHT update accepted at a rising edge is observable immediately after that edge, with zero additional clock-cycle latency. predict_taken is not a pulse and has no completion or hold/clear interval.

predict_history is combinational when predict_valid is high and exposes the current global history. A qualifying history update accepted at a rising edge is observable immediately after that edge, with zero additional clock-cycle latency. It is not a pulse; its defined value persists between history updates whenever predict_valid is high.

The circuit specification imposes no numeric clock period and no propagation-delay law. For the evaluated trace only, the timebase is one full cycle per row: row k is sampled after settling and before its active edge, and that edge computes the state used by row k+1. Thus row k denotes k times the interface step interval after settling; it does not imply a 10 ns clock tick. The interface provides no numeric step_ns or sample_offset_ns value.

5. Behaviour

Only the low n bits of each PC and history operand participate in the parameterized design. The prediction address is the unsigned n-bit XOR of predict_pc and the current n-bit global branch history. The training address is the unsigned n-bit XOR of train_pc and train_history. Each address selects one of the 2**n PHT states.

When predict_valid is high, predict_taken is the most-significant bit of the selected two-bit PHT state: SNT and LNT predict 1'b0, while LT and ST predict 1'b1. predict_history simultaneously equals the current global branch history. A change of predict_pc can change predict_taken combinationally but cannot change predict_history, select training state, or itself cause an edge update. When predict_valid is low, predict_taken is 1'bx and predict_history is n unknown bits; predict_pc then has no observable effect and ordinary prediction-history advancement is disabled, while qualifying training remains active.

On every rising edge with predict_valid high, the ordinary next global history is the previous history shifted toward the most-significant end with the pre-edge predict_taken appended as bit 0. For the concrete n = 7 instance, this law is `{previous_history[5:0], pre-edge predict_taken}`; the result is truncated at the documented n-bit history boundary. This update requires the prior history and selected prediction to be known; otherwise the resulting history remains unknown.

On every rising edge with train_valid high, the PHT state at `train_pc XOR train_history` increments by one for train_taken equal to 1, saturating at ST (2'b11), or decrements by one for train_taken equal to 0, saturating at SNT (2'b00). The arithmetic is unsigned and its stored result is exactly two bits at the PHT-state write boundary. An uninitialized selected state remains unknown under training until reset has established a state. Repeated asserted edges perform repeated saturating updates. A simultaneous prediction of that address sees the pre-edge PHT state; the updated state becomes visible immediately after the edge.

On a rising edge with both train_valid and train_mispredicted high, the next global history is `{train_history[n-2:0], train_taken}`. For n = 7 this is `{train_history[5:0], train_taken}`. This correction overrides simultaneous ordinary prediction-history advancement. It fully defines the corrected history from the supplied training inputs even if the prior history was unknown. When train_mispredicted is low, training still updates the selected PHT state but does not itself correct history. When train_valid is low, train_taken, train_mispredicted, train_history, and train_pc have no effect.

Prediction-history advancement and PHT training are independent effects of the same rising edge. A valid misprediction changes both the selected PHT state and the global history. A simultaneous non-mispredicted training request and valid prediction trains the selected PHT state and performs the ordinary prediction-history advancement. A simultaneous valid misprediction and prediction trains the selected PHT state but uses the correction, discarding the ordinary history update. There is no transaction completion pulse, cancellation state, or implicit clear: state is retained whenever no applicable update replaces it.

## Normative clarification after closure validation

All non-reset state updates are determined from values sampled immediately before a rising edge of clk and become externally observable immediately after that edge. Falling edges do not update state. Assertion of areset is asynchronous and has priority over every edge-qualified operation; after deassertion, the established reset state is retained until a later rising edge performs a qualifying update. Before areset has ever been asserted, the power-up state and any prediction derived from it remain unknown as already specified.

For ordinary prediction-history advancement, predict_valid alone is not sufficient to overwrite the current history. At a rising edge with predict_valid high, the history is shifted and the pre-edge predict_taken value is appended only when both the pre-edge history and that selected prediction are known. If either is unknown, no ordinary history write occurs: the history retains its complete pre-edge value and its pre-edge known or unknown status. In particular, a history made known by reset or by a valid misprediction correction remains known and unchanged when a later ordinary prediction selects an uninitialized PHT entry. This hold rule does not affect PHT training at the same edge and is superseded by a simultaneous train_valid and train_mispredicted correction, which sets history from train_history and train_taken as specified. Outputs in a row observe the pre-edge state; accepted updates have one-edge latency to the next such row and no additional output register or completion pulse.
